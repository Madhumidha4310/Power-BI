# 📊 Sales Dashboard – Power BI

## 📌 Project Overview

This project is an interactive **Sales Dashboard developed using Microsoft Power BI**.

The dashboard provides a visual overview of sales performance, profit, discount, orders, product sub-categories, regions, and yearly trends. Interactive slicers allow users to filter the dashboard and explore the data from different perspectives.

---

## 🎯 Objectives

The main objectives of this Power BI project are:

* Analyze overall sales performance.
* Understand profit generated from sales.
* Analyze discount information.
* Track total orders.
* Analyze total quality.
* Compare sales and profit across different years.
* Understand category-level performance.
* Analyze profit distribution across sub-categories.
* Filter the dashboard based on year, region, sub-category, and quantity.

## 📊 Dashboard Overview

The dashboard is titled:

### **Sales Dashboard**

It contains multiple KPI cards, slicers, and charts for analyzing business performance.

## 📌 Key Performance Indicators

The dashboard includes the following KPI cards:

### 💰 Total Sales

Displays the overall sales value from the dataset.

### 📈 Total Profit

Displays the total profit generated from the sales.

### 🧾 Total Orders

Shows the total number of orders.

### ⭐ Total Quality

Displays the total quality measure available in the dataset.

### 🏷️ Discount

The dashboard also includes sales-related discount information for performance analysis.

## 🎛️ Interactive Filters

The dashboard provides multiple slicers that allow users to interactively filter the visualizations.

### Quantity Filter

Users can filter the dashboard based on **Quantity**.

### Sub-Category Filter

Users can select a particular **Product Sub-Category**.

### Year Filter

Users can analyze the data for different **years**.

### Region Filter

Users can filter the dashboard based on different **regions**.

These filters dynamically affect the dashboard visualizations.

## 📈 Visualizations

### 1. Profit by Sub-Category

A **Pie Chart** is used to display profit distribution across different product sub-categories.

This helps identify which sub-categories contribute more or less to the overall profit.

### 2. Category Analysis

A **Column Chart** is used to analyze categories against yearly information.

This provides a visual comparison of category-level data across the available years.

### 3. Yearly Sales and Profit Analysis

A **Line Chart** compares multiple measures across years, including:

* Profit
* Sales
* Discount

This helps identify changes in business performance over time.
