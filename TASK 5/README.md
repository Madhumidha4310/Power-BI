# Healthcare Data Cleaning and Analysis using Power BI

## Project Overview
This project focuses on cleaning and preparing healthcare data using Microsoft Power BI. Power Query Editor is used to identify data quality issues, transform the dataset, and prepare the data for analysis and visualization.

## Objective
- Import healthcare data into Power BI.
- Identify and handle missing values.
- Detect and remove duplicate records where appropriate.
- Correct data types and standardize inconsistent values.
- Transform and validate the dataset.
- Create meaningful visualizations from the cleaned data.

## Tools and Technologies
- Microsoft Power BI Desktop
- Power Query Editor
- Data Visualization
- Data Transformation

## Tasks Performed
1. Imported the healthcare dataset into Power BI.
2. Inspected the dataset for data quality issues.
3. Cleaned missing and duplicate values where appropriate.
4. Corrected column data types and standardized values.
5. Renamed columns and removed unnecessary fields where required.
6. Validated the transformed dataset.
7. Prepared the data for reporting and visualization.

## Project File
`Healthcare_cleaning.pbix`

## Expected Outcome
The project demonstrates data cleaning and transformation techniques in Power BI and prepares healthcare data for meaningful analysis and reporting.

## How to Open the Project
1. Install Microsoft Power BI Desktop.
2. Download or clone this repository.
3. Open `Healthcare_cleaning.pbix` in Power BI Desktop.
4. Review the available report pages and data model.
5. Open **Transform data** to inspect the Power Query transformations.
