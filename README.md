# Power BI – Data Cleaning, Modeling & Dashboard Projects

## 📌 Project Overview

This repository contains my practical learning and project work using **Microsoft Power BI**.

The projects focus on preparing raw data, performing data cleaning and transformation, creating data models, developing dashboards, and presenting information through interactive visualizations.

The main purpose of these tasks is to understand how raw data can be transformed into meaningful reports using Power BI.

---

## 🎯 Objectives

* Understand the process of importing and preparing data.
* Perform data cleaning and transformation.
* Develop relationships between tables.
* Create suitable data models for reporting.
* Build interactive dashboards.
* Use visualizations to represent business and financial information.
* Create calculations and measures using DAX.
* Analyze sales and stock-related information through reports.
